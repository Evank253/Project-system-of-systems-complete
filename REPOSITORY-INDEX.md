## Integrity and review rules

1. Preserve the canonical ZIP and its metadata as the reference package.
2. Verify file hashes against `FILE-MANIFEST.json` before asserting byte-for-byte integrity.
3. Treat test outcomes as unverified unless logs and execution environment are available.
4. Mark untested or unreproduced items `NOT_MEASURED`.
5. Keep credentials, API keys, passwords, and private tokens out of the repository.
6. The convenience source-tree reference is a path-organization aid only; it is not a verified rebuild.

## Constitutional invariant

**CAPABILITY ≠ EVIDENCE ≠ VERIFICATION ≠ QUALIFICATION ≠ AUTHORITY**

Human Authority remains external to the software system. No model, tool, test, evidence record, or qualification result can self-authorize or become Human Authority.
